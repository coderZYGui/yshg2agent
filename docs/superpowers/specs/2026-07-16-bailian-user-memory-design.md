# 百炼用户级长期记忆设计

## 目标

让同一账号在不同会话中复用同一个百炼长期记忆体，使百炼应用能保存并召回用户的长期信息。

## 范围

- 在 `users` 表新增可空且唯一的 `memory_id`。
- 首次聊天时创建百炼记忆体，并保存返回的 `memory_id`。
- 后续聊天把该 `memory_id` 传入 `Application.call`。
- 保持既有 SSE 流式输出、会话记录和附件处理不变。

## 调用流程

1. 聊天请求取得当前用户。
2. 若用户没有 `memory_id`，调用 DashScope SDK 的创建长期记忆接口；创建失败则终止本次聊天并返回错误。
3. 保存返回的 ID 后，所有该用户的聊天请求都携带 `memory_id` 调用百炼应用。
4. 百炼应用负责提取、保存及召回记忆内容；应用控制台必须启用长期记忆功能。

## 验收

- 单元测试验证首次请求创建并保存 ID，第二次请求复用该 ID。
- 真实验证以同一账号完成两轮聊天：第一轮写入一个唯一偏好，第二轮询问该偏好并确认百炼回答正确。
- 创建或调用失败时不降级为无记忆调用。
